# Supplementary Material

This repository provides supplementary results for the paper **“Containment-Consensus using Binary Measurements under Intermittent Connectivity.”**

The supplementary document includes:
- **Control Gain Analysis:** Numerical results evaluating the effects of different control gains on convergence time and control effort.
- **SITL Simulation:** Description and demonstration of the Software-in-the-Loop (SITL) simulation using nano-quadrotors in a Gazebo–ROS 2 environment.
